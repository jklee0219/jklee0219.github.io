1. 수집하지 않는 정보

본 도구는 제3자의 개인정보를 일절 수집하지 않습니다. 회원 가입, 로그인, 문의 양식 등 이용자 정보를 받는 기능이 없습니다. 방문자 분석 도구나 광고 추적도 사용하지 않습니다.

2. 처리하는 정보

운영자 본인의 계정에 게시하기 위해 다음 값만 운영자의 개인 컴퓨터에 저장합니다.

항목목적보관
계정 액세스 토큰본인 계정에 게시로컬 설정 파일, 만료 시 갱신
계정 식별자게시 대상 지정로컬 설정 파일
게시 결과 링크중복 게시 방지로컬 기록 파일

위 정보는 외부 서버로 전송되지 않으며, 각 플랫폼의 공식 API 호출에만 사용됩니다.

3. 제3자 제공

어떠한 정보도 제3자에게 제공·판매·공유하지 않습니다.

4. 영상 파일의 임시 공개

게시 과정에서 플랫폼이 영상 파일을 가져갈 수 있도록 해당 파일 하나를 임시 주소로 1분 미만 공개하며, 전송이 끝나면 즉시 내립니다. 이때 공개되는 것은 게시 대상 영상 자체이며 개인정보는 포함되지 않습니다.

5. 권한 철회

운영자는 각 플랫폼의 설정에서 본 도구의 접근 권한을 언제든 해제할 수 있으며, 해제 시 저장된 토큰은 즉시 무효가 됩니다.
